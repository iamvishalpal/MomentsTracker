# MomentsTracker ⏳

> Your life is made of moments. Keep track of them.

**MomentsTracker** is a personal event and moments tracking web application built to help you keep important dates, memorable occasions, and life events organized in one place.

🔗 **Live Website:** [momentstracker1.netlify.app](https://momentstracker1.netlify.app/)

## 📌 Why MomentsTracker?

I wanted a simple way to track the events and moments that matter to me. Many existing apps offer similar functionality behind paid plans, so I decided to build my own alternative.

I used an AI-assisted, vibe-coding approach to turn this idea into a working web application.

This is a personal project built around a simple goal: **create a useful tool for yourself instead of always searching for one.**

## 🛠️ Tech Stack

- **React 19** — User interface
- **TypeScript** — Type-safe development
- **Vite** — Development server and build tooling
- **Tailwind CSS 4** — Styling
- **Supabase** — Backend integration
- **Netlify** — Live deployment

## 🚀 Getting Started

Want to explore or run the project locally?

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/iamvishalpal/MomentsTracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd MomentsTracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🔒 Configuration & Security

The project includes Supabase integration. If you run it locally, check the source code and configuration to determine whether Supabase environment variables are required.

- Never commit private API keys, passwords, or secret environment files.
- Use appropriate Supabase access policies for any stored user data.
- Keep public client configuration separate from server-side secrets.
